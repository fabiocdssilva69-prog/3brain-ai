3BRAIN · Código aberto · feito com o Claude CodeOpen source · built with Claude Code

Veja o ritmo da sua cota do Claude antes de ela acabar. See how fast your Claude quota is going before it runs out.

O Claude Quota Meter deixa o Reator Mark II por cima de todas as janelas. Ele mostra a janela de 5 horas e a da semana, quanto falta para cada uma reiniciar e a força: o seu ritmo real de gasto dividido pelo que ainda cabe até o reinício. Claude Quota Meter keeps the Arc Reactor Mark II on top of every window. It shows your 5-hour and weekly windows, how long until each one resets, and the force: your real spending rate divided by what still fits until the reset.

Como funcionaHow it works

Da linha de estado à cor do reator.From the status line to the reactor's colour.

1

O Claude Code informaClaude Code reports

Em cada resposta, o Claude Code entrega rate_limits ao script da linha de estado: quanto já foi usado e quando reinicia cada janela, a de 5 horas e a de 7 dias.On every reply, Claude Code hands rate_limits to your status-line script: how much is used and when each window resets, the 5-hour one and the 7-day one.

2

Uma leitura a cada 3 minutosOne reading every 3 minutes

O gancho grava uma leitura por passo de 3 minutos, numa grade comum em UTC, e escreve na sua linha de estado 5h 23% · 7d 41% · resets 2h14.The hook saves one reading per 3-minute step on a shared UTC grid and prints 5h 23% · 7d 41% · resets 2h14 in your status line.

3

A forçaThe force

O ritmo é quanto a janela subiu de verdade nos últimos 40 minutos (sessão) ou 24 horas (semana). Força = ritmo ÷ o que cabe até o reinício, na janela que chegaria a 100% primeiro.The rate is how much the window really rose in the last 40 minutes (session) or 24 hours (week). Force = rate ÷ what fits until the reset, in the window that would reach 100% first.

4

O reatorThe reactor

A velocidade e a cor seguem a força. Com as mesmas leituras, dois computadores mostram exatamente os mesmos números, e os testes provam isso.Speed and colour follow the force. With the same readings, two computers show exactly the same numbers, and the tests prove it.

Leitura exata, opcionalExact reading, optional

A linha de estado não traz a semana por modelo e só atualiza enquanto o Claude Code responde. Com "fonte": "oauth" no config, o medidor pergunta ao mesmo endpoint que o Claude Code usa no /usage, no máximo uma vez a cada 3 minutos. Esse endpoint não é uma API pública documentada. O token é lido na hora, vai só para api.anthropic.com e nunca é impresso nem guardado. Fica desligado até você ligar.The status line has no per-model week and only updates while Claude Code is replying. With "fonte": "oauth" in the config, the meter asks the same endpoint Claude Code uses for /usage, at most once every 3 minutes. That endpoint is not a documented public API. The token is read at request time, goes only to api.anthropic.com and is never printed or stored. It stays off until you turn it on.

Quem fezWho made it

Ficou útil demais para guardar só para nós. 3BRAIN is two founders, no employees and no outside capital, writing their products with Claude Code every day. The meter started as an internal tool: with many sessions and agents running at once, we needed to see the spending rate before the quota ran out. It turned out too useful to keep to ourselves.
